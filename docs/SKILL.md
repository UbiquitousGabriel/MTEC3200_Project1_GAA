# Build a screen

1. Read the matching file in `docs/wireframes/`.
2. List every element you see before writing code.
3. Map each element to a component in `docs/components.md`.
4. If a component is missing, add it from the component library and list it in `docs/components.md`.
5. Build the screen with placeholder data.
6. Do not touch other screens.

## How to talk to me

- [Example: Show me the element list and wait for my OK before coding.]
- [Example: Keep explanations short.]

## Design approach

- [Example: Minimal. Lots of white space.]
- [Example: Accessibility first. Clear labels and good contrast.]

## When you're done

- Tell me which files you changed.
- Stop so I can check the screen manually against the wireframe.
